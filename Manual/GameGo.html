On the Subject of GameGo

To the moon!

You are a highly valued employee at your local videogame trading store, GameGo, tasked with working the front desk. Located in the highly populous town of Manhattan (Kansas, not New York), you can expect upwards of 2 customers on any given day. Provide each customer with the bestest of service, and you can begin to dream of that bonus that will never come.

Each customer will bring in a videogame that they wish to trade in for a game in the store's stock. Successfully serve 2 customers to solve the module and go home for the day.

Clicking the Arrow button will change displays between the cashier's desk and the game shelves. Games in stock will display their Retail Values below the game case. Customers will also state a need, a like, and a dislike. Select the customer to switch between their game and their stated preferences. Award points to the games in stock by following the below steps.

  1. Evaluate the customer's game to determine it's Trade-In Value using the tables on page 2.
  2. Award 5 points to games having a Retail Value within $5 of the Trade-In Value (inclusive), 4 points if within $10, 3 points if within $15, 2 points if within $20, 1 point if within $25, and 0 points otherwise.
  3. Deduct 2 points from a game in stock if it is the same as the customer's (console doesn't matter).
  4. Award 3 points to games that fulfill a need.
  5. Award 1 point to games that fulfill a like.
  6. Deduct 1 point from games that fulfill a dislike.
  7. Finally, select the game with the highest point value. If multiple games are tied, select the game with the lower Retail Value.

After completing a successful trade, the customer's game will replace the selected game on the shelf and a Retail Value will be automatically assigned. If you did not give the customer the proper game, a strike will be issued without losing any progress.

All videogames, case covers, and game details are visible in the Appendix. Details are ordered as such from top to bottom: Title, Primary Genre, Secondary Genre, Target Audience, and Play Style.
